# Phase 8.1 Plan 03: Search Reports Dashboard Summary

**The Search reports page is now a dashboard in the style of Kentico's Community Portal reporting screen, built only from the admin design system:**
- a period bar with ‹ › stepping;
- grouped KPI tiles that choose the charted metric;
- a trend chart with a 7-day rolling average and a paged table view;
- a period breakdown and response-time detail in side panels;
- a "Needs attention" card;
- a query table whose actions look like native listing row icons.

The 30-day figures match SQL.
