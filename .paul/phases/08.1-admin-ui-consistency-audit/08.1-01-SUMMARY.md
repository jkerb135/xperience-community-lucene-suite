# Phase 8.1 Plan 01: Admin UI Consistency Audit Summary

**Every Suite admin screen was compared with live native Kentico 31.9.1 screens. The audit found:**
- the report query table's rows overlap one another (Must);
- two side panels drop keyboard focus when they close (Must);
- the query tester's toolbar is laid out unlike native listings (Must; this is the user's complaint);
- four cross-screen inconsistencies (Should).

The user chose to fix every Must and Should in two plans.

## Accomplishments

- **The user's concern turned out to be a different problem than it looked.** The chips and the search box already render exactly as native (same Tag colour, size and radius; same search pill). The real cause is the form-style layout: a labelled field, a detached Filter button, and chips sharing the Filter row.
- **A shipped bug surfaced that 08-02 missed.** Query table rows are 50 px high but their content is 104 px (three stacked action buttons), so rows overlap at every width.
- **The focus regressions were confirmed against native.** Native Content hub returns focus to its Filter button; our Filter and Contact-groups panels drop it to the body.
- **The 0 px gaps share one root cause.** `Row` inside a `Stack` resets `margin-top`; the query tester already had a comment about this trap.
