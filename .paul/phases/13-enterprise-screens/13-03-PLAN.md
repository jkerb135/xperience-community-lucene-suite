## Design
```
Search reports (existing template, Convention 8 dashboard)
├─ period row, Callout "Recent days are not final" (unchanged)
├─ KPI Paper: Volume | Quality groups; tile = eyebrow, value, delta + Sparkline 64×22 bottom-right
│    (tone colour; selected tile: white stroke on ACCENT); footnote "Select a metric to chart it below."
├─ grid 2fr / 1fr:
│   Trend Paper (unchanged: Switch "Show as table", TrendChart)
│   Fix these first Paper (11-02 data and actions kept): each finding row = kind eyebrow, query (600) +
│     "{n} searches" right, DataBar 160 px (ContentGap: no-result %, alert tone; RelevanceMiss: CTR, alert;
│     BuriedAnswer: avg position as share of 10, neutral; SlowQuery: slow share, alert; Regression: changed rate),
│     existing fix links + RowActions; Show all insights; Divider; Response time (TextWithLabel ×3)
├─ Search terms Card: NameToggleButtons; Table columns Query | Searches (DataBar, product, scaled to page max) |
│   No results (DataBar alert 0–100) | CTR (DataBar success 0–100) | Avg. pos. | p95 | Actions (4 icons)
│   RangeFooter: "{from}–{to} of {total} queries" · Select "Rows per page" 10/25/50 (140 px) · Pagination
│   (other) LabelWithTooltip (unchanged)
└─ States: loading Spinner (as today); empty Callout quickTip OnDesk + secondary "Open query tester";
   error NotificationBarAlert + secondary S "Retry" (re-runs the last request), last report at opacity 0.6
```
- **DataBar:** value text (min-width 44, right-aligned, tabular-nums) + an `aria-hidden` track (6 px, radius 3, `var(--color-background-highlighted)`, 72 px default) filled with the tone's runtime token colour (TONE_COLOR). The number stays the readable text.
- **Sparkline:** an `aria-hidden` SVG polyline (stroke 1.5, round joins and caps). Gaps at nulls, like TrendChart.
- **Colours:** tokens only. The handoff hex values map to the existing TONE_COLOR runtime tokens; verify each with getComputedStyle at APPLY.

## AC-1: Sparklines

```gherkin
Given the reports page with a range of N days
Then each of the six KPI tiles shows a sparkline of that metric's daily values from the same report response (no extra request), in the tile's tone, white on the selected tile, aria-hidden
And tiles keep their accessible names and aria-pressed behaviour unchanged
```

## AC-2: Query table data bars and range footer
```gherkin
Given the Search terms table
Then Searches shows a DataBar scaled to the largest value on the current page, No results and CTR show DataBars scaled 0–100 %, each keeping the number as text
And under the table "{from}–{to} of {total} queries", a "Rows per page" Select (10, 25, 50) and Pagination are shown; changing the page size goes back to page 1 and is remembered with the existing per-index report state (sessionStorage)
And the server accepts only 10, 25 or 50 (anything else → the query error message), default 25
And the (other) row, sort switch and row actions behave as before
```

## AC-3: Insights card restyled, behaviour kept
```gherkin
Given findings exist
Then each finding row shows the query (600) with "{searches} searches" on the right and a 160 px DataBar for its kind (ContentGap no-result %, RelevanceMiss CTR, BuriedAnswer average position, SlowQuery slow share, Regression the worsened rate), plus the existing evidence, fix links and actions
And the no-findings fallback, All insights panel (same rows), Divider and Response time are kept
```

## AC-4: Empty and error states
```gherkin
Given a range with no searches
Then a quickTip Callout "No searches in this period" says "Reports fill in once visitors search the site. Searches made in the query tester are not tracked." with a secondary "Open query tester" button (goes to the query tester page)
Given a failed report request
Then the alert keeps its text, adds a secondary S "Retry" button that re-runs the last request, and the last loaded report below is marked stale until a successful load
And text never drops below 4.5:1 contrast: the 60 % opacity applies only to graphics (sparklines, trend bars, data-bar fills), while text keeps full colour and a low-emphasis line "Showing the last loaded report." sits under the alert (handoff deviation for WCAG contrast) <!-- audit-added -->
And Retry uses the same latest-request-wins path as period changes (a stale answer never overwrites a newer one) and is disabled while its request is in flight <!-- audit-added -->
And the empty state appears under exactly the condition the current "No searches" card uses (no searches in the range), never for a failed or still-loading request <!-- audit-added -->
```

## AC-5: No regressions
```gherkin
Then all report numbers, sorts, (other), deltas, range stepping, handoffs, Block suggestion and insights behave as before
And at ~670 and ~1270 px content width there is no overflow, table rows stay one line (50 px), action icons stay on one line
And every colour resolves at runtime; dotnet build (Debug, Release) 0 warnings; full .NET suite, client tests and tsc pass
```
